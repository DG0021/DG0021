### 🚀 Projeto em Destaque

#### 🔮 Oráculo Henrique — Sistema de Agendamentos

Desenvolvimento de uma aplicação web Full Stack para um profissional autônomo, com o objetivo de facilitar a apresentação de serviços, organização de horários e gerenciamento de agendamentos.

O projeto conta com:

**Frontend:**
- Interface pública para apresentação dos serviços e valores.
- Layout responsivo, adaptado para dispositivos móveis.
- Consulta de horários disponíveis.
- Sistema de solicitação de agendamentos.
- Integração com WhatsApp para facilitar o contato com clientes.

**Backend:**
- API REST desenvolvida com Python e FastAPI.
- Banco de dados SQLite.
- Sistema de autenticação utilizando JWT.
- Proteção de rotas administrativas.
- Gerenciamento de serviços, horários e agendamentos.
- Cadastro e gerenciamento de clientes.
- Controle de status de pagamentos e atendimentos.

**Painel Administrativo:**
- Login administrativo com autenticação.
- Visualização e gerenciamento de agendamentos.
- Organização da agenda e disponibilidade de horários.
- Gerenciamento de serviços.
- Acompanhamento de pagamentos e atendimentos.

**Tecnologias utilizadas:** Python, FastAPI, SQLite, JavaScript, HTML, CSS, JWT e Git.

Projeto desenvolvido na prática, desde a estruturação do banco de dados até a integração entre frontend e backend, com foco em resolver uma necessidade real.
